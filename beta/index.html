Why I invited you

I need honest reactions, not polished reviews.

Couples Alarm helps two partners check whether one hears a bundled alarm tone the other does not, then confirm it together before scheduling an alarm.

Please use the setup, listening test, alarm creation, and partner handoff naturally. If anything feels unclear or unreliable, that is exactly what I need to hear.

This is a consumer alarm utility, not a hearing test or medical assessment, and it will not find a suitable sound for every couple.

Beta safety

Keep a trusted backup alarm

Please do not rely on this beta as your only alarm for anything important. Test the selected tone from the phone’s intended bedside position and keep using an alarm you already trust.

How to give feedback

Tap Beta Feedback inside Couples Alarm for the short guided form, or use the web feedback form. You can also reply directly to Brian’s message.

Already installed?

Open TestFlight, select Couples Alarm, and tap Update if it appears. The current beta is build 68.

TestFlight is not installed

The install button will offer Apple’s free TestFlight app. Install it, then return to the same button and join the Couples Alarm beta.

The link will not open

Open this page in Safari on the iPhone you will use for testing. If the beta says it is full or unavailable, contact Brian instead of forwarding the link.
