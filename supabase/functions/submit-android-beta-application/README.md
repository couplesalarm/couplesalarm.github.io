# Android beta applications

The public form at `/beta/android/#application` asks only for the Google Play email and saves through this endpoint with the project's public anon JWT. Gateway JWT verification stays enabled; the handler checks the site origin and email. It never accepts applicant reads or tester admission requests. A valid public JWT is not compared byte-for-byte with the runtime's generated anon token, which can represent the same project with different token timestamps.

Signups are stored in `public.couples_alarm_android_beta_applications` in the existing Couples Alarm project `xqdqgsbkapvlskcldmpe`, database `postgres`, host `db.xqdqgsbkapvlskcldmpe.supabase.co`. RLS is enabled with no public policies; `anon` and `authenticated` have no table privileges. Server-only credentials write the validated email and signup-notice version. No applicant information is included in a response or logged.

New signups use source `website_android_beta_email_v2` and notice version `android_beta_email_notice_v2`. Submitting the form requests beta contact and access as disclosed beside the button; there is no consent checkbox. Device, age, explicit consent-checkbox and 14-day-commitment columns stay null. Extra fields from cached older forms are ignored. Do not treat these null fields as failed signup requirements or as confirmed age/commitment. Existing older applications and their original answers are preserved; duplicate emails do not overwrite them.

The existing Supabase project owner can review applications in the project's Table Editor, ordered by `created_at, id`. Duplicate normalized emails retain the original application and consent. This endpoint does not send emails, select or invite testers, add Google Group members, or create purchases. Admission remains a separate organizer action after the existing beta gates. The previous Google Form and its responses are untouched.

The prepared Google Forms admission worker has not been activated and does not read this new source. Use the private table for website applications; do not assume that worker processes them. Application storage and website signup availability do not establish downloadable Google Play beta access.
